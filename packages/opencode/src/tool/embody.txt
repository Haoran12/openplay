Dispatch a character subagent to respond in character based on filtered scene perception plus stable self-knowledge.

The Director calls this tool to have a character act within the narrative. You (the Director) must:

1. **Construct the current perception (`l2View`)**: Filter what this character can perceive right now based on access tags:
   - `Public` / `public` → include for everyone
   - `God Only` / `god-only` → NEVER include (the system will also strip it)
   - `Condition: X` → include only if the character satisfies condition X
   - `self` → include only for the character themselves
   - `participant` → include only if the character was involved in the event
   - `List: A, B` → include only if the character is in the named list

2. **Keep self-knowledge separate from scene perception**:
   - `l2View` should describe what the character can currently perceive in the outside world.
   - Do not rely on `l2View` alone to restate the character's own stable identity every time.
   - The system will add a separate self-knowledge layer from character config/state when available.

3. **Translate numbers into sensory descriptions when they are perceived externally**: Don't write "power level 2500" — write "you sense formidable spiritual pressure."

4. **Pass the situation**: Describe what is happening right now from this character's vantage point.

## Important

- Never paraphrase or hint at God Only information in the L2 view.
- The system will programmatically strip any remaining God Only content from both self-knowledge and scene perception as a safety net.
- Make sure `l2View` contains enough immediate, player-facing scene facts for action, but do not pad it with omniscient lore.
- This tool returns the character's response — you then continue directing the scene.
