Perform deterministic calculations for roleplay world simulation.

## Operations

### date
Calculate the difference between two dates.
- `from`: Start date (format: YYYY-MM-DD or YYYY-MM-DD BC)
- `to`: End date (format: YYYY-MM-DD or YYYY-MM-DD BC)
- Returns: human-readable time span between dates.

### tier
Classify a numeric value into a named power tier.
- `value`: The numeric value to classify.
- `tiers` (optional): Custom tier table as `[{name, min, max, description}, ...]`. Defaults to standard cultivation tiers (Mundane → Transcendent).
  - Standard tiers:
    - Mundane [0, 200): 没有锻炼/修行的普通人
    - Apprentice [200, 1000): 有基础锻炼/修行
    - Adept [1000, 1800): 中坚力量, 需要长时间锻炼/修行, 也是难以突破的瓶颈
    - Master [1800, 2600): 宗师级别, 寻常生灵的极限
    - Ascendant [2600, 6000): 突破凡俗界限, 仙灵的层级
    - Transcendent [6000, Infinity): 极少数存在
- Returns: Tier name with description, progress to next tier.

### delta
Compare two numeric values and describe the significance of the gap.
- `a`: First value.
- `b`: Second value.
- Returns: Absolute difference and qualitative description of the gap.
  - [0, 150): 难分高下, 更看临场发挥
  - [150, 400): 有明显差距, 但是 环境适应性/心态差异/技能克制 可以弥补差距
  - [400, 1000): 差距较大, 难以弥补
  - [1000, Infinity): 碾压, 无法抗衡

### age
Calculate a character's age given birth date and current date.
- `birthDate`: Birth date (format: YYYY-MM-DD or YYYY-MM-DD BC)
- `currentDate`: Current in-game date (format: YYYY-MM-DD or YYYY-MM-DD BC)
- Returns: Age in years.
