Update the current character's own long-term knowledge resources in the roleplay world.

Use this tool to revise stable character-owned knowledge about society, nature, other people, regions, factions, habits, judgments, and recurring understandings that should live outside the transient scene.

## Parameters

- `path`: Path relative to the current character's `knowledge/` directory.
- `content`: The complete file content to write.
- `create` (optional, default true): Whether to create the file if it does not exist.

## Knowledge File Directory Contract

Files under `{character}/knowledge/` hold character-owned durable understanding:

- `world_base.yaml`: Overall worldview and natural laws — broad, general rules.
- `social_and_world.md`: Overall social landscape and political culture.
- `nature_and_body.md`: Natural environment and body/sensory experience.
- `<name>.md`: Knowledge about a **specific** person, region, or faction.

**Important:**

- Write to `world_base.yaml`/`social_and_world.md`/`nature_and_body.md` only for **broad, general** observations.
- For **specific** persons, regions, or factions, create dedicated files (e.g., `li_ming.md`, `northern_frontier.md`).
- Stats, abilities, history, identity, beliefs → `profile.yaml`, not knowledge files.
- One stable topic per file for readability.
- No absolute paths, parent traversal, or non-knowledge paths.
- No public event records or omniscient world truth.
