Update scene and world state files in the roleplay world directory.

Use this tool to persist narrative changes, event records, and state updates to YAML (or other text) files in the world directory.

## Parameters

- `path`: File path relative to the world root directory. Allowed targets are `runtime.yaml` and files under `records/` (for example `records/session-001.yaml`).
- `content`: The complete file content to write.
- `create` (optional, default true): Whether to create the file if it doesn't exist.

## Important

- Always write the complete file content — this tool overwrites the existing file.
- The path is resolved relative to the world root directory (where openplay.json is located).
- Use this for updating runtime.yaml and writing event records.
- This tool cannot write character resource paths, absolute paths, or parent-relative paths.
- Subjective character memory must be updated through the dedicated character-memory flow, not through `scene_update`.
- Treat `runtime.yaml` as the authoritative live state for the roleplay side panel. If scene facts or present-character facts changed, persist them here in the same turn.
