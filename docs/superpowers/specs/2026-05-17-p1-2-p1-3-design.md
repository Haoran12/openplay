# P1-2 & P1-3 Design: 形态切换支持 & openplay init 命令

## P1-2: 形态切换支持

### 概述

形态切换是角色状态管理的一部分，通过 `runtime.yaml` 中的 `form` 字段实现。

### 范围

**文档任务，无需代码改动。**

### 实现

在 `runtime.yaml` 模板或文档中说明 `form` 字段：

```yaml
# runtime.yaml 示例
character_states:
  孟缘:
    form: human        # 当前形态：human/beast/spirit 等
    location: 洞庭湖畔
    status: normal     # 身体状态
    activity: 修炼     # 当前活动
```

### 使用方式

Director 通过 `scene_update` 工具更新 `runtime.yaml`：

```
scene_update(
  path: "runtime.yaml",
  content: "更新后的 YAML 内容（含新 form 值）"
)
```

| 文件 | 操作 |

| `docs/openplay/runtime-yaml-schema.md` | 新增，说明 runtime.yaml 字段 |
| `docs/openplay/PROGRESS.md` | 更新，标记 P1-2 完成 |

## P1-3: openplay init 命令

### 概述

CLI 命令，用于初始化或补全世界目录结构。

### 功能

1. 检测并补全缺失的目录结构
2. 检测并补全缺失的配置字段
3. 从 `runtime.yaml` 最简世界升级为完整 `openplay.json`

### 命令用法

```bash
openplay init              # 在当前目录补全
openplay init --path foo   # 在指定目录补全
openplay init --name "云梦泽"  # 非交互，指定名称
```

### 补全逻辑

| 缺失项 | 补全内容 |
|--------|----------|
| `openplay.json` | 生成默认配置（id 自动生成，name 用户输入） |
| `runtime.yaml` | 生成空场景状态模板 |
| `characters/` | 创建空目录 |
| `social/` | 创建空目录 |
| `worldview/` | 创建空目录 |
| `records/` | 创建空目录 |

### openplay.json Schema 扩展

新增 `name` 字段：

```jsonc
{
  "id": "wld_a1b2c3d4...",   // 自动生成，唯一标识
  "name": "云梦泽",           // 用户输入，UI 展示名称
  "roleplay": {
    "worldPath": ".",
    "currentDate": null,      // 用户后续配置
    "narrativeStyle": {},
    "recordThreshold": 5
  },
  "agent": {
    "director": {
      "model": { "id": "claude-sonnet-4-20250514" },
      "isDirector": true
    }
  }
}
```

### runtime.yaml 模板

```yaml
# 当前场景状态
current_scene:
  location: null
  time: null
  atmosphere: null

# 环境信息（由 Director 推断）
environment: {}

# 在场角色
present_characters: []

# 角色即时状态
character_states: {}

# 叙事风格（可覆盖 openplay.json 配置）
narrative_style: {}
```

### 交互流程

```
$ openplay init
? 世界名称: 云梦泽
✓ 创建 openplay.json (id: wld_abc123, name: 云梦泽)
✓ 创建 runtime.yaml
✓ 创建 characters/
✓ 创建 social/
✓ 创建 worldview/
✓ 创建 records/
完成！世界目录已初始化。
```

### 从 runtime.yaml 升级

如果目录只有 `runtime.yaml`（最简世界），`openplay init` 会：

1. 读取 `runtime.yaml` 内容
2. 生成 `openplay.json`（id 自动生成，name 从 runtime.yaml 提取或询问用户）
3. 补全缺失目录
